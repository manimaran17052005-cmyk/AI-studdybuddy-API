# Project Documentation

## Title
AI StudyBuddy API

## Purpose
An API-based AI study assistant for students.

## Technology
Python, FastAPI, MongoDB, JWT and an optional AI provider.

## Main Modules
Authentication, Users, Notes, AI, Quizzes, Flashcards and Progress.

## Future Enhancements
- Web/mobile frontend
- PDF/document upload
- RAG-based document Q&A
- Admin dashboard
- Analytics
- Notifications
